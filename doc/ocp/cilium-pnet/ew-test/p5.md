## p5 - primary privnet:blue, secondary privnet:red

Combination of
- primary connection to privnet as in [p1](./p1.md)
- secondary connection to privnet as in [p2](./p2.md)

```shell
iserver create k8s pod --namespace c --name p5 --template netshoot \
    --network pnet,blue,10.10.10.5 \
    --network pnet,red,20.20.20.5
```

```yaml
apiVersion: v1
kind: Pod
metadata:
  annotations:
    k8s.v1.cni.cncf.io/networks: c/red-subnet-0@eth1
    privnet.isovalent.com/network-attachment: '{"network": "blue", "ipv4": "10.10.10.5"}'
    privnet.isovalent.com/secondary-network-attachments: '[{"network": "red", "ipv4":
      "20.20.20.5"}]'
  name: p5
  namespace: c
spec:
  containers:
  - command:
    - sleep
    - infinite
    image: nicolaka/netshoot:latest
    name: netshoot
    securityContext:
      capabilities:
        add:
        - IPC_LOCK
        - SYS_RESOURCE
        - NET_RAW
        - NET_ADMIN
      runAsUser: 0
```
