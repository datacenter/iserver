## p1 - primary privnet:blue

POD primary connection to private network `X` with ipv4 address `Y` requires annotation

```yaml
metadata:
  annotations:
    privnet.isovalent.com/network-attachment: '{"network": "X", "ipv4": "Y"}'
```

```shell
iserver create k8s pod --namespace a --name p1 --template netshoot --network pnet,blue,10.10.10.1
```

```yaml
apiVersion: v1
kind: Pod
metadata:
  annotations:
    privnet.isovalent.com/network-attachment: '{"network": "blue", "ipv4": "10.10.10.1"}'
  name: p1
  namespace: a
spec:
  containers:
  - command:
    - sleep
    - infinite
    image: nicolaka/netshoot:latest
    name: netshoot
    securityContext:
      capabilities:
        add:
        - IPC_LOCK
        - SYS_RESOURCE
        - NET_RAW
        - NET_ADMIN
      runAsUser: 0
```
