## p2 - primary (pod) and secondary (privnet:blue)

POD in namespace `N` with secondary connection to private network `X`, ipv4 address `Y` belonging to subnet `Z` requires two annotations where `N/X-Z` selects the NetworkAttachmentDefinition auto-created for network `X`.

```yaml
metadata:
  annotations:
    k8s.v1.cni.cncf.io/networks: N/X-Z@eth1
    privnet.isovalent.com/secondary-network-attachments: '[{"network": "X", "ipv4":"Y"}]'
```

```shell
iserver create k8s pod --namespace a --name p2 --template netshoot --network pod --network pnet,blue,10.10.10.2
```

```yaml
apiVersion: v1
kind: Pod
metadata:
  annotations:
    k8s.v1.cni.cncf.io/networks: a/blue-subnet-0@eth1
    privnet.isovalent.com/secondary-network-attachments: '[{"network": "blue", "ipv4":"10.10.10.2"}]'
  name: p2
  namespace: a
spec:
  containers:
  - command:
    - sleep
    - infinite
    image: nicolaka/netshoot:latest
    name: netshoot
    securityContext:
      capabilities:
        add:
        - IPC_LOCK
        - SYS_RESOURCE
        - NET_RAW
        - NET_ADMIN
      runAsUser: 0
```

## IP Stack

Notes:
- `eth0` with default route and /32 address from POD CIDR
- `eth1` with route to privnet subnet and /32 privnet address as per annotation
- p2 can reach p1 over privnet blue in L3-way i.e., no L2 reachability

```
$ oc exec --namespace a p2 -- ip a

    link/ether da:6d:48:c4:db:01 brd ff:ff:ff:ff:ff:ff link-netnsid 0
    inet 10.128.1.173/32 scope global eth0
52170: eth1@if52171: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1450 qdisc noqueue state UP group default 
    link/ether 0e:a6:dd:6d:7d:b6 brd ff:ff:ff:ff:ff:ff link-netnsid 0
    inet 10.10.10.2/32 scope global eth1
```
