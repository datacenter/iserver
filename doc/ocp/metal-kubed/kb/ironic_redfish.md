# Ironic and Redfish requirements

[[Back]](../README.md)

Redfish allows for very different valid implementations, some of which are not compatible with Ironic (and thus Metal3). The Ironic project publishes a Redfish interoperability profile – a JSON document that describes the required and optionally supported Redfish API features. Its available versions can be found in the [Ironic source tree](https://opendev.org/openstack/ironic/src/branch/master/redfish-interop-profiles)
- [Ironic Profile v1.1.0](./OpenStackIronicProfile.v1_1_0.json)
- [Ironic Profile v1.2.0](./OpenStackIronicProfile.v1_2_0.json)
