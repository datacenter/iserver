# CLI Web Terminal - Create via Task

## HowTo

```
[
  {
    "terminal": {
      "operator": {
        "channel": "xyz"
      }
    }
  }
]
```

```
# iserver set ocp task --cluster bm1 --filename C:\tmp\task.json --no-confirm
```

Notes:
- [operator](./create_operator.md) triggers workflow execution with input parameters
