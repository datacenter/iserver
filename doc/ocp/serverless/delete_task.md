# Serverless - Delete via Task

## HowTo

```
[
  {
    "serverless": {
      "operator": {
        "channel": "xyz"
      }
    }
  }
]
```

```
# iserver delete ocp task --cluster bm1 --filename C:\tmp\task.json
```

Notes:
- [operator](./delete_operator.md) parameters are ignored for delete workflow
