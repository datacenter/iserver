# VAST Operator - Get

## Workflow

- get vast operator subscription
- get vast crds: `VastCSIDriver`, `VastCluster`, `VastStorage`
- get storage class generated by `VastStorage`
- get persistent volume claims associated with vast storage classes

## Requirements

None

## Configurable options

```
# iserver get ocp vast 
  --cluster TEXT   Cluster Name
  --verbose        Verbose output
  -v, --view TEXT  [state|res|all]  [default: state]
```

## Example (view:state)

```
# iserver get ocp vast --cluster bm1
```
