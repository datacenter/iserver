# Node Feature Discovery Operator

Node Feature Discovery Operator detects hardware features and labels the nodes as explained in [RedHat OpenShift documentation](https://docs.redhat.com/en/documentation/openshift_container_platform/4.18/html/specialized_hardware_and_driver_enablement/psap-node-feature-discovery-operator).

## Life Cycle Management Commands

Command | Intent | Details
--- | --- | ---
iserver get ocp nfd | check the NFD operator state | [Link](./get.md)
iserver set ocp nfd | install and configure NFD operator | [Link](./create_operator.md)
iserver set ocp task | in task way | [Link](./create_task.md)
iserver delete ocp nfd | uninstall NFD operator | [Link](./delete_operator.md)
iserver delete ocp task | in task way | [Link](./delete_task.md)
