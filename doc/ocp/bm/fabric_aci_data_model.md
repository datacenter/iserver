# ACI Fabric - Data model

ACI fabric configuration is defined in controller item in fabric.json

```
{
    "controller": [
        {
            "type": "aci"
            "apic": "<connector-name>",
            "domain": "<domain-name>",
            ...
        }
    ],
    "server": [...]
}
```

## Controller properties

Some properties have to be explicitly user-defined, others can be autogenerated (*) based on built-in defaults and names from tenant, mo_name and domain propertes.

### Common

Name | Type | Mandatory | Auto-Generation (*) | Description
--- | --- | --- | --- | ---
apic | string | True | False | [Link](./fabric_aci_data_model_connector.md)
domain | string | True | False | Defines server interfaces to controller mapping.
mo_name | string | True | False | Used in managed object name generation. Must be globally unique.
tenant | string | True | False | Tenant in APIC. Must exist.
l3out | string | True | False | L3out in APIC. Must exist in either 'controller.tenant' or 'common' tenant.
vrf  | string | True | False | VRF in APIC. Must exist in either 'controller.tenant' or 'common' tenant.
vlan_pool | dict | False | True | [Link](./fabric_aci_data_model_vlan_pool.md)
physical_domain | dict | False | True | [Link](./fabric_aci_data_model_physical_domain.md)
aaep | dict | False | True | [Link](./fabric_aci_data_model_aaep.md)
cdp | dict | False | True | [Link](./fabric_aci_data_model_cdp.md)
lldp | dict | False | True | [Link](./fabric_aci_data_model_lldp.md)
l2 | dict | False | True | [Link](./fabric_aci_data_model_l2.md)
link_level | dict | False | True | [Link](./fabric_aci_data_model_link_level.md)
port_channel | dict | False | True | [Link](./fabric_aci_data_model_port_channel.md)
policy_group | dict | False | True | [Link](./fabric_aci_data_model_policy_group.md)

## Shortest One

Many properties can be generated leading to the smallest possible controller definition examples

### EPG/BD

```
{
    "type": "aci",
    "apic": "<value>",
    "domain": "<value>",
    "mo_name": "<value>",
    "tenant": "<value>",
    "l3out": "<value>",
    "vrf": "<value>"
}
```
